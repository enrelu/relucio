# Spanish / English website

## Scope
English translation of the existing website, including all 23 blog articles, sales landing, profile/CV, projects, photography interface, contact flow and six tools. Original Spanish content and article URLs are preserved. This work is isolated in `feature/english-version`; no production merge is authorized.

## Routes and preference
- Spanish uses the existing routes; English lives under `/en/` with English page and article slugs.
- Detection runs only on `/`, the unqualified entry point: primary `navigator.language` starting with `es` selects Spanish; every other language selects English.
- Explicit localized/deep URLs win over detection. A French-language browser can therefore read a shared Spanish article without being bounced elsewhere.
- The persistent native ES/EN selector remembers manual choice in `relucio-language`. A saved `es`/`en` choice wins over browser detection at `/`.
- Switching languages preserves query strings and profile section IDs. Blog heading IDs are mapped to the equivalent heading in the other language.
- Blocked local storage does not stop language detection or navigation. Without JavaScript, explicit English URLs render in English and native fallback links provide language navigation; automatic detection cannot run.

## Files
- `src/i18n/routes.ts`: centralized page/article/category/tag pair resolution.
- `src/i18n/blog-map.json`: source IDs, English slugs, taxonomies and equivalent heading anchors.
- `src/content/blog/`: Spanish originals, unchanged.
- `src/content/blog-en/`: complete static English articles with `translationKey` pointing to the Spanish content ID.
- `src/pages/en/`, `src/components/en/`, `src/data/portfolio.en.ts`: localized templates, interaction messages and portfolio data. The layout, navigation, footer, language state and styles are shared.
- `src/i18n/en-ui.json`: editorial glossary/reference for localized strings. It is not a runtime translation service; localized templates contain the final reviewed text.
- `scripts/check-i18n.mjs`: repeatable static integrity checks after building.

There is no translation API in the browser or production runtime. Drafts were translation-assisted; sales copy, interaction wording and personal essays were edited for natural English. Translation preserves the source articles’ claims and historical publication dates rather than silently updating them. Images, credentials and third-party source materials stay as originally published.

## Blog maintenance
For each new article, add its English Markdown file, preserve the original `pubDate` and factual references, and add an explicit row to `blog-map.json`. Use a genuine `updatedDate` only when the article itself changes. Keep technical acronyms (CTEM, MFA, DSPM, etc.) and named organizations intact. Update the paired heading maps when headings change.

Update localized templates/components alongside their Spanish counterparts if the site UI changes. Do not silently route untranslated content to an English URL. The integrity checker currently requires a complete one-to-one article set.

## SEO
Each localized page has its own canonical URL and `lang`. Shared layout emits Spanish/English alternate links, `x-default`, and locale-specific Open Graph metadata. The generated sitemap contains both language versions. The English article template links explicitly to the Spanish original and marks article structured data as English.

## Contact and external services
The website’s booking steps, labels, errors, confirmation and prefill headings are localized. The English Calendly embed requests `locale=en`. Calendly account-owned event titles/descriptions and Flickr photo titles are external content, not rewritten by this PR. No calendar event or live booking was created during QA.

## Validation
- `npm run check:i18n`: 184 generated pages; 23 complete article pairs; 89 non-redirect English pages; no missing local links, paired headings, canonical/alternate metadata or sitemap entries.
- Browser QA: 96 route/width/theme combinations at 320, 390, 768 and 1440 px; 8 browser-language/saved-preference cases.
- All 23 article pairs switched in both directions, including the original Spanish URL containing `ñ`.
- Manual preference, query/hash retention, paired article headings, profile sections, local-storage denial and no-JS language links tested.
- Contact empty-form validation and translated tool feedback tested. Password generation length and Base64 encoding verified without printing generated passwords.
- Visual inspection: English home desktop/mobile/dark, contact mobile, profile mobile, blog listing, complete article and tools mobile. Screen-reader-only labels and intentional blog excerpt/breadcrumb truncation are not layout failures.
- Blog structural review: headings/tables and protected third-party links retained. Owned article links localized; original dates and hero assets retained.
- Third-party Calendly/Flickr live content is not an English editorial review of those services.
